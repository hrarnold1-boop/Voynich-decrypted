## Descripción del Proyecto
Este repositorio contiene el paquete académico estandarizado del sistema operativo del Manuscrito Voynich (MS 408), formalizado como un *Tractatus Cosmographico-Medicus et Balneatorius* redactado en latín medieval mediante taquigrafía de sustitución.
